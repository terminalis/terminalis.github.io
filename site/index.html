terminalis

Signed package repositories for apps by terminalis.

Flatpak repository

To add the repository without installing an app, so software centers list every app in it:

flatpak remote-add --user --if-not-exists terminalis https://terminalis.github.io/packages/flatpak/terminalis.flatpakrepo

New versions then arrive through flatpak update and software centers such as GNOME Software and KDE Discover. The apps use runtimes from Flathub, so that needs the Flathub remote too. An app's .flatpakref adds it by itself.

F-Droid repository

Add it to F-Droid, Droid-ify or Neo Store with this address, which includes the repository's fingerprint. The client then lists every app in the repository and installs their updates.

https://terminalis.github.io/packages/fdroid/repo?fingerprint=E172E436AAECD5F656AFEB2D40F3011C111C114AB1A60507672CEA5ACBDC17D2

In Obtainium, add an app with the "F-Droid Third Party Repo" source, the address https://terminalis.github.io/packages/fdroid/repo and the app's ID.

source github.com/terminalis
